鄰近聖誕節，最不可或缺的就是聖誕樹。加上網路上大家對於「大二聖誕節」這個特別日子所產生的魔咒，團隊決定製作一個應景且可以同時解決單身問題的裝置。

在外觀設計上選用聖誕樹為主體（參考了扭蛋機的設計），作品中央會放置一棵聖誕樹，並用透明板將它包圍，營造出類似水晶球的感覺。

在程式碼與硬體實作部分，裝置結合了四種主要且有趣的互動功能：
* **戀愛匹配**：測試者透過觸摸愛心裝置進行匹配，並於 OLED 螢幕上顯示匹配度。
* **抽籤**：透過觸摸裝置並利用伺服馬達控制，讓籤從裝置內掉出來。
* **下雪**：聖誕樹旁放置了下雪功能，按下觸控部分即可讓雪花飛出來。
* **戀愛測驗**：共有五道題目，透過序列埠監控視窗進行作答並計算測驗結果。

整體裝置還會透過 OLED 顯示目前的模式，並配有溫濕度顯示以及不同的背景音樂（如心跳聲、聖誕音樂等），大幅增添了互動感與節慶氛圍。
