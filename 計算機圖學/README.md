# 3D 太空船星空探險 (3D Spaceship Adventure)[cite: 55]

## 🔗 相關連結
* **遊戲 Demo**：[YouTube 操作影片](https://youtu.be/lUMXKO-tjx8)

## 🎮 遊戲簡介
這是一款以 3D 太空為背景的星空探險小遊戲[cite: 55]。玩家將駕駛太空船，在充滿隕石的宇宙中盡可能地向前飛行並收集星星以獲取高分[cite: 55]。遊戲開啟後會自動開始倒數計時，快來挑戰您的反應極限！[cite: 55]

## ⌨️ 遊戲操作說明
玩家可透過以下鍵盤按鍵來控制太空船的移動與視角：
* `W`：前進[cite: 55]
* `S`：後退[cite: 55]
* `A`：向左移動[cite: 55]
* `D`：向右移動[cite: 55]
* `Z`：向上移動[cite: 55]
* `X`：向下移動[cite: 55]
* `K`：轉換視角（可以看側面）[cite: 55]

*(註：太空船的上、下、左、右及前進皆有限制，只能在一定的範圍內移動[cite: 55]。)*

## 📜 遊玩規則與機制
* **時間與計分**：遊戲限時 30 秒，評分標準取決於玩家飛行的距離。每前進 30 單位即可加 1 分[cite: 55]。
* **加分道具 (星星)**：遊戲場景中會出現兩個星星。碰到星星可大幅加 20 分，碰觸後星星即會消失[cite: 55]。
* **遊戲結束條件**：
  * 若生命值歸零 (life = 0)，遊戲將會提前結束，此時倒數計時也會隨之暫停[cite: 55]。

## 💥 碰撞處理機制 (Collision Handling)
本遊戲在太空船與隕石的碰撞處理上，特別設計了流暢的判定與邊緣滑動機制，提升了操作手感與合理性：

* **狀態轉換判定 (避免連續扣血)**：玩家初始生命值為 3[cite: 55]。系統會判斷太空船的碰撞狀態，只有在**「從未碰撞轉換為有碰撞」**的瞬間，才會觸發生命值減一的懲罰[cite: 55]。這意味著在貼著隕石移動的期間，系統不會因為偵測到重疊而連續扣除生命值導致玩家瞬間死亡[cite: 55]。
* **邊緣滑動移動 (Edge Sliding)**：當太空船撞擊到隕石時，若玩家依然持續按著前進鍵 (`W`)，太空船不會完全卡死不動，而是會**沿著隕石的邊緣移動 (滑動)**[cite: 55]。玩家可以利用這個物理特性順著隕石邊緣滑行，直到完全脫離碰撞範圍為止[cite: 55]。
* **邊界限制 (Boundary Limits)**：除了障礙物碰撞外，宇宙空間也設有無形的物理範圍限制，確保太空船在上下左右與前方都無法飛出設計好的遊戲視野邊界[cite: 55]。

## 🛠️ 技術實作細節
* **3D 模型載入 (3DS Loader)**：專案底層使用 C/C++ 實作了 `.3ds` 3D 模型的解析與載入器 (`3dsloader.cpp` 與 `3dsloader.h`)[cite: 56, 57]。
* 系統能夠成功讀取 3D 建模軟體匯出的區塊資料 (Chunks)，將模型的頂點座標 (Vertices)、多邊形面 (Polygons/Faces) 以及貼圖座標 (Mapping Coordinates) 載入至遊戲引擎中，藉此渲染出精緻的太空船與隕石等 3D 物件[cite: 56]。
