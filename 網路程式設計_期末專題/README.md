## 🎮 專案簡介
本專案為網路程式設計課程之期末專案，遊戲靈感來自於《瑪利歐派對 超級巨星》中的小遊戲「數數123」。這是一款需要多名玩家連線進行的網路小遊戲，考驗玩家的觀察力與反應能力。

## 📝 遊戲規則
* 遊戲必須集齊四個玩家連線後才會開始遊玩。
* 遊戲開始後，每個玩家的畫面皆會保持一致。
* 玩家需根據畫面給予的題目，使用鍵盤的「上」、「下」鍵來控制自己的計數數字。
* 一輪遊戲中會隨機播放三個影片供玩家計算數量。
* 每個影片播放結束後，系統會根據玩家的計數與標準答案來計算分數。
* **計分規則**：計數與答案完全一致得 3 分，相差 1 得 2 分，相差 2 或 3 得 1 分，相差 3 以上得 0 分。
* 遊戲過程中若有任何玩家離線，遊戲便會直接結束。
* 三個影片播放完畢後，系統會給出所有玩家的最終總分與名次排名。

## 🛠️ 系統架構與使用技術
本專案採用 Client-Server 架構進行開發，並運用了以下網路通訊與程式技術：
* **TCP 連線**：用於客戶端與伺服器端之間的連線，並負責傳遞與接收玩家的計數訊息。
* **UDP 廣播**：伺服器端透過 UDP 廣播的方式，將隨機選擇的題目資訊與影片名稱同步發送給所有客戶端。
* **Multi-thread (多執行緒)**：伺服器端實作了多執行緒，以便同時處理多個客戶端的連線要求與資料接收。
* **GUI 圖形化介面**：利用 Python 的 `tkinter` 套件來開發使用者介面，顯示圖片、文字以及處理各種事件（如播放影片或離線等）。
* **動態影片播放**：透過 OpenCV (`cv2`) 將影片切割成多張圖片幀，接著連續放到 `tkinter` 畫布上並頻繁更新，以實現影片播放的效果。

## 💻 模組架構分配
專案主要分為 `server.py` 與 `client.py` 兩個部分，各自負責不同的功能：

### Server (伺服器端)
* 負責處理與接收玩家的 TCP 連線。
* 接收各個客戶端傳來的計數數字，統整後再透過 TCP 傳送給所有客戶端。
* 負責隨機選擇題目，並利用廣播 (Broadcast) 的方式傳送題目資訊。
* 處理玩家離線的狀況，並通知其他玩家結束遊戲。

### Client (客戶端)
* 負責呈現 GUI 畫面，包含題目顯示與影片播放。
* 透過 TCP 處理並顯示多個客戶端的計數與畫面內容。
* 根據收到的標準答案進行分數計算。
* 在遊戲結束時顯示所有玩家的排名結算畫面。

## 💡 困難挑戰與開發心得
* **資料分配與架構設計**：在開發初期，判斷客戶端和伺服器端分別要處理哪些部分的資料傳送花費了許多精力。
* **GUI 版面與更新**：隨著專案越加越多功能，GUI 介面的元件位置與畫面更新時機需要不斷地調整與判斷。
* **影片播放技術**：要在 Tkinter 中播放影片是一門新學的技術，研究如何將影片切圖並時常更新畫面花了一段時間才順利實作成功。
* **反思與未來展望**：因為事前規劃不夠完備就開始動工，導致過程中經常遇到需要東補西漏、頻繁修改架構的情況。如果一開始能想得更周全，就能減少反覆修改的問題。目前專案雖然已經處理了部分同步問題，但仍有改善空間（例如等待所有玩家真正到齊才開始遊戲畫面等細節），這也是未來可以繼續優化的方向。
