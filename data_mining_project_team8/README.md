# 資料探勘期末專案：蝴蝶雜交偵測 (Butterfly Hybridization Detection)[cite: 16]

## 🎮 專案簡介
本專案為資料探勘課程之期末專案，主要目標是利用深度學習的電腦視覺技術，偵測蝴蝶影像是否為雜交種 (Hybrid vs. Non-hybrid)[cite: 16, 17]。
由於訓練資料集存在極度嚴重的「資料不平衡」問題（Hybrid 僅 66 張，而 Non-hybrid 有 1589 張），本專案特別設計了從**資料採樣端**到**損失函數端**的雙重平衡機制，並搭配深度微調策略，成功克服了稀有類別難以被辨識的挑戰[cite: 17, 22, 23]。

## 🛠️ 資料前處理與資料增強 (Data Augmentation)
為確保模型訓練的穩定性與泛化能力，我們進行了以下影像處理：
* **基礎處理**：將圖片統一 Resize 至 `224x224` 以符合 ResNet50 標準尺寸，轉換為 PyTorch Tensor 格式，並套用 ImageNet 的平均值與標準差進行正規化[cite: 15, 19]。
* **資料增強**：訓練時引入多種隨機變化，包含隨機水平/垂直翻轉、隨機旋轉 (±15度)、隨機仿射變換，以及隨機更改亮度、對比與顏色，藉此增加樣本多樣性[cite: 15, 20]。

## ⚖️ 解決資料不平衡的雙重機制
1. **資料端平衡 - 加權隨機採樣 (Weighted Random Sampling)**
   * 根據類別數量計算權重，數量越少的類別權重越大[cite: 15, 22]。
   * 採用「有放回抽樣」，讓模型在訓練過程中能有更高的機率重複抽取到稀有的 Hybrid 樣本（過採樣），猶如放大了 Hybrid 在抽籤輪盤上的面積[cite: 15, 22]。
2. **損失函數端 - Focal Loss (γ = 3.0)**
   * 捨棄傳統 Cross Entropy，改用 Focal Loss[cite: 15, 23]。
   * 透過設定較大的 Gamma 值 ($\gamma=3.0$)，大幅降低模型對高信心度樣本的損失權重，強制模型將注意力聚焦在最難分辨的 Hybrid 邊緣案例上[cite: 15, 23]。

## 🧠 模型架構與訓練優化
本專案選用已在 ImageNet 上預訓練的 **ResNet50** 進行遷移學習[cite: 15, 24]。
* **深度微調 (Deep Fine-Tuning)**：我們採用分層訓練策略。凍結了 Layer 1 與 Layer 2 確保基礎特徵萃取能力；解凍高階的 Layer 3 與 Layer 4 讓模型精準學習蝴蝶翅膀細微紋理，最後重新訓練 FC 層以對應二分類任務[cite: 15, 24]。
* **訓練效能與穩定性優化**：
  * **梯度累積 (Gradient Accumulation)**：設定累積 4 步，模擬出 4 倍大的 Batch Size (32) 效果，使梯度更新方向更為穩定[cite: 15, 25]。
  * **自動混合精度 (AMP)**：在矩陣乘法等運算採用 FP16，而損失計算與梯度更新保留 FP32，大幅提升訓練速度並節省 GPU 記憶體[cite: 15, 25]。

## 📊 實驗流程與結果
* **兩階段訓練策略**：
  1. **Phase 1 (參數尋優)**：將資料依分層抽樣切分為 80% Train, 10% Validation, 10% Internal Test，用於尋找最佳超參數與驗證模型有效性[cite: 15, 21]。
  2. **Phase 2 (全量重訓)**：為讓模型學習到最多特徵，將 Phase 1 切分出的驗證集與測試集全部加回訓練集 (Train+Val+Test) 進行最終模型訓練[cite: 15, 21]。
* **模型解釋性**：透過 **Grad-CAM** 視覺化熱力圖 (Attention Map)，確認最終優化模型 (G5) 確實能精準聚焦在蝴蝶翅膀上的關鍵特徵區塊[cite: 28]。
* **最終驗證表現**：
  * **整體準確率 (Accuracy)**：高達 **98%**[cite: 31]。
  * **Hybrid 類別**：Precision 0.80, Recall **0.96**[cite: 30]。
  * **Non-hybrid 類別**：Precision 1.00, Recall 0.99[cite: 30]。
  * 實驗證明，我們的架構有效解決了 66 vs 1589 的極端不平衡問題，達成極高的召回率與準確率[cite: 17, 30, 31]。
